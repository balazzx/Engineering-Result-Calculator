# 🎓 Engineering Result Calculator

## 📌 About the Project

The Engineering Result Calculator is a simple Python-based application developed to calculate semester GPA, CGPA, and overall percentage for engineering students.

This program accepts subject marks for two semesters, calculates subject-wise grades and grade points, and generates a final academic result summary.

## ✨ Features

- Accepts marks for two semesters.
- Calculates subject-wise grades.
- Calculates grade points based on marks.
- Displays individual semester results.
- Calculates Semester GPA.
- Calculates Semester Percentage.
- Calculates Final CGPA.
- Calculates Overall Percentage.
- Validates marks between 0 and 100.
- Displays a final academic summary.

## 🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- Loops
- Lists
- Exception Handling

## 📚 Grade Calculation

| Marks | Grade | Grade Point |
|---|---|---:|
| 90–100 | O | 10 |
| 80–89 | A+ | 9 |
| 70–79 | A | 8 |
| 60–69 | B+ | 7 |
| 50–59 | B | 6 |
| Below 50 | U | 0 |

## 🧮 Calculation

**Semester GPA:**

Total Grade Points / Number of Subjects

**Semester Percentage:**

Total Marks / Number of Subjects

**Final CGPA:**

(Semester I GPA + Semester II GPA) / 2

**Overall Percentage:**

(Semester I Percentage + Semester II Percentage) / 2

*Note: These calculations use equal subject weighting and are intended for this project. Official university calculations may follow different credit-based rules.*

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python "sem result.py"
```

5. Enter the marks for Semester I and Semester II.
6. View your semester results and final summary.
